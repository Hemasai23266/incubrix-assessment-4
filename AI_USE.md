# AI_USE

| Tool | Used for |
|---|---|
| Claude Code (Anthropic, model "Claude Sonnet 5.5") | Pair-programming: scaffolding the FastAPI service, connectors, rules engine, mock platforms, tests, compose file and documentation. All generated code was run, tested and reviewed by the submitter before inclusion. |

No AI model or API is called at runtime by the service. No AI-generated media is produced; the output manifest carries `rights.ai_generated`,
which reflects whether the *content being published* was marked AI-generated by the caller.

The submitter is responsible for, and can explain, the architecture decisions: one connector per platform type with one catalogue row
per destination, the runtime as the only DB writer, the unique `posts.idempotency_key` and unique `(scope, key)` idempotency records as the
duplicate guard, and certification as publish -> confirm -> status -> delete -> verify -> evidence.
